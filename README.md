# TP1 - Simulateur de Cinétique

Simulation numérique de la décomposition d'un médicament dans le sang.

## Installation

Aucune dépendance externe. Python 3.8+ requis.

## Utilisation

\`\`\`bash
python main.py
\`\`\`

Affiche un rapport détaillé de la simulation avec Cmax et durée optimale.

## Structure

- `cinetique.py` : Calculs de concentration et conversion
- `analyse.py` : Simulation et analyse statistique
- `main.py` : Point d'entrée
